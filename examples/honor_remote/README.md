# HONOR 遥控器作业示例

本示例保留课程题目，供检查作业配置与交付清单。通过 `assignment_plan(config_path="examples/honor_remote/assignment.json")` 可以查看阶段、预计输出和缺失项。课程原文见 [课程要求](COURSE_REQUIREMENTS.md)。

| 项目 | 状态 |
| --- | --- |
| 作业配置与命名规则 | 已提供。默认选择 FBX，可将 `export_formats` 改为 `["obj"]` |
| 课程参考图、学号、姓名 | 缺失，模板保留空值 |
| 中模场景与低模 | 待制作。课程要求手工重拓扑，需人工检查 |
| 三视角合并图、高低模对照图、UV 图 | 待生成 |
| 低模导出 | 待生成 |
| 烘焙图 | 课程清单未要求，示例中关闭 |
| 验收 | `ready: false`，使用 `assignment_check` 核对真实文件 |

补齐输入后，可使用 [通用工作流](../../README.md#作业工作流) 生成交付文件。
