# 作业要求（原文整理）

## 一、课后作业：华为 HONOR 遥控器制作

### 制作要求

1. 运用三维制作软件 Maya 完成一个遥控器的单体模型制作，具体参考给出图片。
2. 作业在限定时间内提交，工程文件 Maya 源文件以 `学号-姓名-作品名称` 格式命名，例如 `20190056-张三-遥控器.mb`。
3. 工程文件包含：高质量模型中模，理清楚图层和大纲视图列表。
4. 提交包含正、侧、背三角度视图的整张截图（跟参考图类似，不要多张图，请合并为一张）。

## 二、课后作业：华为鸿蒙遥控器拓扑与 UV 拆分

### 制作要求

1. 运用三维制作软件 Maya，通过手动重新拓扑完成对第二讲作业模型的低模制作，并完成相关模型的 UV 展开工作。
2. 提交 FBX 或 OBJ 格式模型文件，并以 `学号-姓名-作品名称` 格式命名，例如 `20190056-张三-遥控器`。
3. 工程文件包含：高质量模型高、低模，理清楚图层和大纲视图列表。
4. 提交主、顶、左三视角高低模对比图截图，并提交低模 UV 截图。

## 交付清单

- 中模 Maya 源文件（`.mb`）
- 低模 Maya 源文件（`.mb`，如适用）
- 低模 FBX 或 OBJ
- 正/侧/背合并截图
- 主/顶/左高低模对比截图
- 低模 UV 截图

> 学号、姓名未提供，生成文件名时使用占位符并提醒用户替换。
