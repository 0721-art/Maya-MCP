# Maya-MCP — 通用作业场景要求

本文件是产品需求，不是某一次作业的硬编码内容。作业题目、参考图、学号姓名、模型风格都可能变化；MCP 必须服务“Agent 通过对话驱动 Maya 完成建模类作业”的场景。

## 1. 通用能力

MCP Server 必须通过 Maya 内的桥接真实执行，不得用 mock 返回冒充 Maya 结果。工具至少覆盖：

- 场景/对象：查询场景、对象、层级、变换、材质、UV、选择集。
- 建模：基础体、曲线/放样、挤出/倒角/镜像/阵列、布尔、修改器式操作、组合/分离、命名、图层/大纲整理。
- 拓扑：低模重拓扑（优先 `polyRetopo`，按 Maya 版本能力降级）、减面/重建、四边面检查、非流形/三角面检查、对称与吸附。
- UV：平面/圆柱/球形/自动投影、展开、排布、UV 集、UV 快照、UDIM/多象限检查。
- 烘焙：高低模法线/AO/曲率/颜色等贴图烘焙；优先 Maya 原生 `transferMaps`，Arnold 可用时支持 Arnold 烘焙；输出真实图片并回报路径。
- 渲染/截图：正/侧/背/主/顶/左等多视角，合并为单张对比图；视口截图与离线渲染。
- 导出：`.mb`、FBX、OBJ；保留图层/大纲；路径、覆盖保护、错误包装。
- 安全：路径白名单、超时、错误结构、禁止危险命令、可选 safe mode；桥接端口仅本机。

## 2. 多版本 Maya 适配

- 不绑定 Maya 2026；至少设计支持 Maya 2022–2026，能自动发现安装目录和 `mayapy.exe`。
- 桥接代码避免只在 2026 存在的 API；对 `polyRetopo`、Arnold、FBX 插件等按版本/可用性探测并降级。
- 提供 `get_maya_info`：版本、Python、渲染器、插件、能力矩阵。
- 测试矩阵按“已安装版本”运行；未安装的版本明确标记“未实测”，不得声称已支持。

## 3. 作业模板，而非固定题目

- 作业要求是模板：题目、参考图、提交格式、命名规则、截图视角均可配置。
- 内置示例可以是 HONOR 遥控器，但必须放在 `examples/`，通过配置驱动；核心 MCP 工具不得硬编码遥控器、HONOR 或某一套作业步骤。
- 提供“作业工作流”辅助：接收作业说明/参考图/命名规则，生成阶段任务（中模→低模→UV→烘焙→截图→导出→验收），但每个阶段仍调用通用工具。
- 交付时生成 `deliverables/`、`renders/`、`exports/` 和 `docs/` 清单；缺失项明确标注，不伪造。

## 4. 与 Agent 的交互

- MCP stdio 服务可被 DSH、Codex、Claude 等客户端启动；提供 README 配置示例。
- Maya 侧桥接为一个可加载脚本/模块，启动命令端口；Agent 不需要手写 Maya 内部循环。
- 工具返回结构化 JSON，包含 `ok`、`data`、`error`、`warnings`、`artifacts`；长任务支持超时/轮询。
- 所有写操作要有 `overwrite` 保护和明确的输出路径。
